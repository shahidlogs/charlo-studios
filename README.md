# Charlo Studios website

A plain static website. No build step, framework, JavaScript, analytics, or paid hosting dependency.

## Publish with GitHub Pages

1. Create a public GitHub repository, for example `charlo-studios`.
2. Upload `index.html`, `styles.css`, and `favicon.svg` to the repository root (not inside another folder).
3. In the repository, open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, branch **main**, folder **/(root)**, then save.
4. The site will appear at `https://YOUR-USERNAME.github.io/charlo-studios/`. If you name the repository `YOUR-USERNAME.github.io`, its URL will be `https://YOUR-USERNAME.github.io/`.

The site uses relative local asset paths, so either URL shape works. Google Fonts are optional; system fonts are used if they cannot load. The contact buttons open the visitor's email app. To change the contact address, replace both occurrences of `shahidkhanblogger@gmail.com` in `index.html` (including the visible address). Add public links for Charlo and CannonPop when those are available.
